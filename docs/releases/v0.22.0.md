## English

**MeshCentral Windows Client 0.22.0**

### New
- **UDP port mapping:** when mapping a port, choose TCP or UDP (DNS and SNMP come as UDP). The datagrams go through the
  device's agent and the answers come back to whoever asked; a quiet UDP flow closes after two minutes. Remembered
  mappings keep their protocol.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. To install it, download `MeshCentralClient-Setup.exe`
and run it; or keep using `MeshCentralClient.exe` alone, as before. Each file has its `.sha256` fingerprint.

## Español

**MeshCentral Windows Client 0.22.0**

### Nuevo
- **Redirección de puertos UDP:** al redirigir un puerto se elige TCP o UDP (DNS y SNMP vienen como UDP). Los datagramas
  van por el agente del equipo y las respuestas vuelven a quien preguntó; un flujo UDP callado se cierra a los dos
  minutos. Las redirecciones recordadas guardan su protocolo.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Para instalarla, descarga
`MeshCentralClient-Setup.exe` y ábrelo; o sigue usando `MeshCentralClient.exe` solo, como hasta ahora. Cada fichero
lleva su huella `.sha256`.

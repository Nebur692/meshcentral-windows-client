## English

**MeshCentral Windows Client 0.25.2**

### Fixed
- **The device list no longer jumps when you click a row.** A right click or a click on a row cut by the bottom edge,
  closing its menu, or a device changing on the server, scrolled the list several rows, so you could not tell whether you
  had clicked the right one. Now the list only moves when you move through it with the keyboard.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. To install it, download `MeshCentralClient-Setup.exe`
and run it; or keep using `MeshCentralClient.exe` alone, as before. Each file has its `.sha256` fingerprint.

## Español

**MeshCentral Windows Client 0.25.2**

### Corregido
- **La lista de equipos ya no salta al hacer clic en una fila.** El clic derecho o normal en una fila cortada por el borde
  de abajo, cerrar su menú o un equipo que cambiaba en el servidor desplazaban la lista varias filas, y no sabías si habías
  pulsado el que querías. Ahora la lista solo se mueve cuando la recorres con el teclado.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Para instalarla, descarga
`MeshCentralClient-Setup.exe` y ábrelo; o sigue usando `MeshCentralClient.exe` solo, como hasta ahora. Cada fichero
lleva su huella `.sha256`.

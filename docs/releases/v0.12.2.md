## English

**MeshCentral Windows Client 0.12.2**

### Fixed
- **Run commands → As the signed-in user, on Windows.** It did not do what it said: depending on how the device's agent
  runs, the commands ran as the system account, with the user signed in, or never answered. They now really run as that
  user, in cmd or PowerShell.

### Good to know
- If nobody is signed in on that Windows device, it now says so instead of running the commands as the system account.
- It uses a PowerShell of that user and its files, so it needs terminal and files rights on the device. If its group asks
  for consent for terminal sessions, the person there is asked.
- Commands that have not ended after 5 minutes are stopped on the device, with everything they started.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. Otherwise download `MeshCentralClient.exe` and run
it; keep it in a folder of yours so it can update itself. `MeshCentralClient.exe.sha256` is its fingerprint.

## Español

**MeshCentral Windows Client 0.12.2**

### Arreglado
- **Ejecutar órdenes → Como el usuario con sesión iniciada, en Windows.** No hacía lo que decía: según cómo corriera el
  agente del equipo, las órdenes se ejecutaban con la cuenta del sistema, con el usuario dentro, o no contestaban nunca.
  Ahora se ejecutan de verdad como ese usuario, en cmd o PowerShell.

### Conviene saber
- Si no hay nadie con sesión en ese equipo Windows, ahora lo dice, en vez de ejecutar las órdenes con la cuenta del sistema.
- Usa un PowerShell de ese usuario y sus ficheros, así que pide permisos de terminal y de ficheros en el equipo. Si su
  grupo pide consentimiento para las sesiones de terminal, se le pregunta a la persona de allí.
- Las órdenes que no hayan acabado a los 5 minutos se paran en el equipo, con todo lo que hayan lanzado.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Si no, descarga `MeshCentralClient.exe` y
ábrelo; tenlo en una carpeta tuya para que pueda actualizarse. `MeshCentralClient.exe.sha256` es su huella.

## English

**MeshCentral Windows Client 0.12.3**

### Fixed
- **Remote desktop, copying on the device:** letting go of Ctrl before the C (or the X) did not bring what was copied back
  to this PC by itself. It now counts from the moment the keys are pressed. Ctrl+Insert also counts as copying.
- **Remote desktop without an image:** if the device never sends its screen, the window now says so and what to do, instead
  of staying on "Connecting…" for good.
- **Run commands:** the error messages now talk about the commands. Before, a missing right could read as if the server had
  refused the login.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. Otherwise download `MeshCentralClient.exe` and run
it; keep it in a folder of yours so it can update itself. `MeshCentralClient.exe.sha256` is its fingerprint.

## Español

**MeshCentral Windows Client 0.12.3**

### Arreglado
- **Escritorio remoto, copiar en el equipo:** soltar Ctrl antes que la C (o la X) no traía solo a este PC lo copiado. Ahora
  cuenta desde que se pulsan las teclas. Ctrl+Insert también cuenta como copiar.
- **Escritorio remoto sin imagen:** si el equipo no llega a mandar su pantalla, la ventana ahora lo dice, y qué hacer, en vez
  de quedarse para siempre en «Conectando…».
- **Ejecutar órdenes:** los mensajes de error ahora hablan de las órdenes. Antes, un permiso que faltaba podía leerse como
  si el servidor hubiera rechazado la entrada.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Si no, descarga `MeshCentralClient.exe` y
ábrelo; tenlo en una carpeta tuya para que pueda actualizarse. `MeshCentralClient.exe.sha256` es su huella.

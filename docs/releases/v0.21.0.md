## English

**MeshCentral Windows Client 0.21.0**

### New
- **Adding people to a group:** type a name, an email or a user name and the matching accounts show below; taking one
  writes its sign-in name, also for accounts made by single sign-on (OpenID Connect), whose sign-in name nobody knows.
  In device groups and in user groups.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. To install it, download `MeshCentralClient-Setup.exe`
and run it; or keep using `MeshCentralClient.exe` alone, as before. Each file has its `.sha256` fingerprint.

## Español

**MeshCentral Windows Client 0.21.0**

### Nuevo
- **Añadir personas a un grupo:** escribe un nombre, un correo o un usuario y debajo salen las cuentas que encajan; al
  tomar una se escribe su usuario de entrar, también el de las cuentas de inicio de sesión único (OpenID Connect), que
  nadie se sabe. En los grupos de equipos y en los de usuarios.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Para instalarla, descarga
`MeshCentralClient-Setup.exe` y ábrelo; o sigue usando `MeshCentralClient.exe` solo, como hasta ahora. Cada fichero
lleva su huella `.sha256`.

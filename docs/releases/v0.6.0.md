## English

**MeshCentral Windows Client 0.6.0**

### New
- **Remote desktop** (right click → Open remote desktop): the device's screen, live, with mouse and keyboard.
  - **Several displays at once**: "One window per display" opens one window per remote display, each maximised on one
    of your monitors (the extra ones on the last); "Join displays" goes back to one. You can also pick one display or all.
  - **Type clipboard**: types your clipboard on the device as Unicode keys, whatever its keyboard layout — handy for a
    login screen.
  - Quality presets (high, balanced, slow connection), Ctrl+Alt+Del and Windows-key buttons, and the agent's messages
    (for example, while it waits for the user to accept).
  - Keys still held are released when the window loses focus.

### Also in this app
Sign-in with two-factor codes or single sign-on, certificate fingerprint pinning, live device list, terminal, files,
light / dark / Windows theme, and automatic updates.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. Otherwise download `MeshCentralClient.exe` and run
it; keep it in a folder of yours so it can update itself. `MeshCentralClient.exe.sha256` is its fingerprint.

## Español

**MeshCentral Windows Client 0.6.0**

### Novedades
- **Escritorio remoto** (clic derecho → Abrir escritorio remoto): la pantalla del equipo en vivo, con ratón y teclado.
  - **Varias pantallas a la vez**: «Una ventana por pantalla» abre una ventana por cada pantalla remota, cada una
    maximizada en uno de tus monitores (las que sobran, en el último); «Juntar pantallas» vuelve a una. También puedes
    elegir una pantalla o todas.
  - **Escribir el portapapeles**: escribe tu portapapeles en el equipo como teclas Unicode, sea cual sea la distribución
    de su teclado; útil en una pantalla de entrada.
  - Calidades predefinidas (alta, equilibrada, conexión lenta), botones de Ctrl+Alt+Supr y tecla Windows, y los mensajes
    del agente (por ejemplo, mientras espera a que el usuario acepte).
  - Las teclas que sigan pulsadas se sueltan al perder el foco la ventana.

### Además, en esta app
Entrada con código de doble factor o inicio de sesión único, huella fijada del certificado, lista de equipos en vivo,
terminal, ficheros, tema claro, oscuro o como Windows, y actualizaciones automáticas.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Si no, descarga `MeshCentralClient.exe` y
ábrelo; tenlo en una carpeta tuya para que pueda actualizarse. `MeshCentralClient.exe.sha256` es su huella.

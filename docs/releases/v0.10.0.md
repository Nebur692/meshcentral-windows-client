## English

**MeshCentral Windows Client 0.10.0**

### New
- **Users** (button "Users", for administrators):
  - **Create accounts** with email, name and server rights; **edit** them, **set a new password** (optionally asking
    for a new one at the next sign-in, or removing their second factor), **lock** and **unlock**, and **delete**.
  - Only the server rights your account may really give are offered: the server would otherwise answer "ok" and
    change nothing.
  - **User groups**: create, rename and delete them, add and take out members. In "Device groups", **Add user group…**
    gives a whole user group rights on a device group.
- **My account** (button "My account"):
  - **Change the password**.
  - **Authenticator app**: a QR code and its key; the code from the app is checked before it is saved.
  - **Backup codes**: see them, make new ones or delete them.
  - **Security keys**: see and remove them (adding one is done on the website).
  - **Login tokens**: a separate user name and password for scripts and tools, shown once; remove them when no longer
    needed.
- Everything follows the server live: accounts and groups changed on the website or by someone else appear at once.

### Fixed
- When an account left a user group, the device groups it saw through that group stayed in its list.

### Also in this app
Sign-in with two-factor codes or single sign-on, live device list, remote desktop with several displays, terminal with
copy and paste as in PuTTY, files with the Windows clipboard, device details, device actions, device groups, light /
dark / Windows theme, and automatic updates.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. Otherwise download `MeshCentralClient.exe` and run
it; keep it in a folder of yours so it can update itself. `MeshCentralClient.exe.sha256` is its fingerprint.

## Español

**MeshCentral Windows Client 0.10.0**

### Novedades
- **Usuarios** (botón «Usuarios», para administradores):
  - **Crear cuentas** con correo, nombre y permisos de servidor; **editarlas**, **ponerles contraseña nueva**
    (pidiendo, si quieres, que la cambien al entrar, o quitándoles el segundo factor), **bloquearlas** y
    **desbloquearlas**, y **borrarlas**.
  - Solo se ofrecen los permisos de servidor que tu cuenta puede dar de verdad: si no, el servidor contestaría «ok» sin
    cambiar nada.
  - **Grupos de usuarios**: crearlos, renombrarlos y borrarlos, y meter o sacar miembros. En «Grupos de equipos»,
    **Añadir grupo de usuarios…** da permisos en un grupo de equipos a todo un grupo de usuarios.
- **Mi cuenta** (botón «Mi cuenta»):
  - **Cambiar la contraseña**.
  - **App de autenticación**: un código QR y su clave; el código de la app se comprueba antes de guardarla.
  - **Códigos de respaldo**: verlos, hacer otros nuevos o borrarlos.
  - **Llaves de seguridad**: verlas y quitarlas (añadirlas se hace en la web).
  - **Tokens de acceso**: otro usuario y contraseña para guiones y herramientas, que se enseña una sola vez; se quitan
    cuando ya no hacen falta.
- Todo sigue al servidor en vivo: las cuentas y grupos cambiados en la web o por otra persona aparecen al momento.

### Arreglado
- Cuando una cuenta salía de un grupo de usuarios, los grupos de equipos que veía por ese grupo seguían en su lista.

### Además, en esta app
Entrada con código de doble factor o inicio de sesión único, lista de equipos en vivo, escritorio remoto con varias
pantallas, terminal con copiar y pegar como en PuTTY, ficheros con el portapapeles de Windows, ficha del equipo,
acciones sobre equipos, grupos de equipos, tema claro, oscuro o como Windows, y actualizaciones automáticas.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Si no, descarga `MeshCentralClient.exe` y
ábrelo; tenlo en una carpeta tuya para que pueda actualizarse. `MeshCentralClient.exe.sha256` es su huella.

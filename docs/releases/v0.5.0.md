## English

**MeshCentral Windows Client 0.5.0**

### New
- **Files** of a device (right click → Open files): browse its drives and folders, create folders, rename, delete,
  upload (also by dropping files from Explorer) and download, with progress and a cancel button. Every change is
  checked with a new listing; a cut download never leaves a half file that looks whole.

### Also in this app
Sign-in with two-factor codes or single sign-on, certificate fingerprint pinning, live device list, terminal (cmd,
PowerShell, shell), light / dark / Windows theme, and automatic updates.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. Otherwise download `MeshCentralClient.exe` and run
it; keep it in a folder of yours so it can update itself. `MeshCentralClient.exe.sha256` is its fingerprint.

## Español

**MeshCentral Windows Client 0.5.0**

### Novedades
- **Ficheros** de un equipo (clic derecho → Abrir ficheros): explorar sus unidades y carpetas, crear carpetas,
  renombrar, borrar, subir (también soltando ficheros desde el Explorador) y bajar, con progreso y botón de cancelar.
  Cada cambio se comprueba volviendo a listar; una descarga cortada nunca deja un fichero a medias que parezca entero.

### Además, en esta app
Entrada con código de doble factor o inicio de sesión único, huella fijada del certificado, lista de equipos en vivo,
terminal (cmd, PowerShell, shell), tema claro, oscuro o como Windows, y actualizaciones automáticas.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Si no, descarga `MeshCentralClient.exe` y
ábrelo; tenlo en una carpeta tuya para que pueda actualizarse. `MeshCentralClient.exe.sha256` es su huella.

## English

**MeshCentral Windows Client 0.4.0**

### New
- **Single sign-on.** If your MeshCentral offers it (OpenID Connect, SAML, Microsoft, Google, GitHub…), a button signs
  you in on the provider's own page, in the Windows browser: the app never sees that password. Leaving username and
  password empty and pressing **Connect** does the same. Next time, if the provider remembers you, you are in without
  typing anything. An account the server refuses stays out, with a clear message.
- **Smaller download**: the single-file exe is now compressed.

### Also in this app
Sign-in with two-factor codes, certificate fingerprint pinning, live device list, terminal (cmd, PowerShell, shell),
light / dark / Windows theme, and automatic updates.

### Install or update
If you have 0.3.0, the app offers this version by itself. Otherwise download `MeshCentralClient.exe` and run it; keep
it in a folder of yours so it can update itself. `MeshCentralClient.exe.sha256` is its fingerprint.

## Español

**MeshCentral Windows Client 0.4.0**

### Novedades
- **Inicio de sesión único.** Si tu MeshCentral lo ofrece (OpenID Connect, SAML, Microsoft, Google, GitHub…), un botón
  te hace entrar en la propia página del proveedor, en el navegador de Windows: la app no ve nunca esa contraseña. Dejar
  usuario y contraseña vacíos y pulsar **Conectar** hace lo mismo. La próxima vez, si el proveedor te recuerda, entras
  sin escribir nada. Una cuenta que el servidor rechaza se queda fuera, con un mensaje claro.
- **Descarga más pequeña**: el exe de un solo fichero va ahora comprimido.

### Además, en esta app
Entrada con código de doble factor, huella fijada del certificado, lista de equipos en vivo, terminal (cmd, PowerShell,
shell), tema claro, oscuro o como Windows, y actualizaciones automáticas.

### Instalar o actualizar
Si tienes la 0.3.0, la app te ofrece esta versión sola. Si no, descarga `MeshCentralClient.exe` y ábrelo; tenlo en una
carpeta tuya para que pueda actualizarse. `MeshCentralClient.exe.sha256` es su huella.

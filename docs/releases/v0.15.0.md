## English

**MeshCentral Windows Client 0.15.0**

### New
- **Install in any folder:** the installer's first page now asks whether to install for your account only (as until
  now, no administrator) or for all users. For all users it asks for administrator and installs in Program Files, or in
  any folder you choose (for example `D:\Program Files`), with the app in everyone's Start menu.
- **A clear message instead of "Error 5: Access denied":** if you choose a folder your account cannot write in, the
  folder page says so and lets you choose another one, before anything is installed.
- **Installed for all users, it still updates:** the app downloads the new installer, checks its SHA-256 fingerprint
  and opens it; Windows asks for administrator, and the app opens again when it ends. Installed for your account only,
  it updates as before.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. To install it, download `MeshCentralClient-Setup.exe`
and run it; or keep using `MeshCentralClient.exe` alone, as before. Each file has its `.sha256` fingerprint.

## Español

**MeshCentral Windows Client 0.15.0**

### Novedades
- **Instala en cualquier carpeta:** la primera página del instalador pregunta ahora si instalar solo para tu cuenta
  (como hasta ahora, sin administrador) o para todos los usuarios. Para todos pide administrador e instala en
  Archivos de programa o en la carpeta que elijas (por ejemplo `D:\Program Files`), con la app en el menú Inicio de
  todos.
- **Un mensaje claro en vez de «Error 5: Acceso denegado»:** si eliges una carpeta en la que tu cuenta no puede
  escribir, la página de la carpeta te lo dice y te deja elegir otra, antes de instalar nada.
- **Instalada para todos, se sigue actualizando:** la app baja el instalador nuevo, comprueba su huella SHA-256 y lo
  abre; Windows pide administrador y la app se vuelve a abrir al acabar. Instalada solo para tu cuenta, se actualiza
  como hasta ahora.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Para instalarla, descarga
`MeshCentralClient-Setup.exe` y ábrelo; o sigue usando `MeshCentralClient.exe` solo, como hasta ahora. Cada fichero
lleva su huella `.sha256`.

## English

**MeshCentral Windows Client 0.9.0**

### New
- **Device groups** (button "Device groups"):
  - **Create, rename and delete** groups. Deleting asks first and says how many devices go with it.
  - **Users and rights**: give other accounts rights on a group, with every right of the website as checkboxes, change
    them or take them away. A user name the server does not know is named, never dropped silently.
  - **Add devices**: an **invitation link** (a public page with the installers; whoever opens it needs no account), the
    **Windows agent** with the group built in (64-bit, ARM 64-bit or 32-bit), or the **Linux / BSD / macOS command**.
- **Move devices to another group** (right click on one or several devices).
- Groups created, changed or deleted on the website or by someone else appear at once.
- Only what your account is allowed to do is offered.

### Also in this app
Sign-in with two-factor codes or single sign-on, live device list, remote desktop with several displays, terminal with
copy and paste as in PuTTY, files with the Windows clipboard, device details, device actions (wake, power, messages,
commands), light / dark / Windows theme, and automatic updates.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. Otherwise download `MeshCentralClient.exe` and run
it; keep it in a folder of yours so it can update itself. `MeshCentralClient.exe.sha256` is its fingerprint.

## Español

**MeshCentral Windows Client 0.9.0**

### Novedades
- **Grupos de equipos** (botón «Grupos de equipos»):
  - **Crear, renombrar y borrar** grupos. Borrar pregunta antes y dice cuántos equipos se van con él.
  - **Usuarios y permisos**: dar permisos en un grupo a otras cuentas, con todos los permisos de la web como casillas,
    cambiarlos o quitarlos. Un nombre de usuario que el servidor no conoce se dice, nunca se pierde sin avisar.
  - **Añadir equipos**: un **enlace de invitación** (una página pública con los instaladores; quien lo abre no necesita
    cuenta), el **agente de Windows** con el grupo dentro (64 bits, ARM de 64 bits o 32 bits), o la **orden de Linux, BSD
    o macOS**.
- **Mover equipos a otro grupo** (clic derecho en uno o varios equipos).
- Los grupos creados, cambiados o borrados en la web o por otra persona aparecen al momento.
- Solo se ofrece lo que tu cuenta tiene permiso para hacer.

### Además, en esta app
Entrada con código de doble factor o inicio de sesión único, lista de equipos en vivo, escritorio remoto con varias
pantallas, terminal con copiar y pegar como en PuTTY, ficheros con el portapapeles de Windows, ficha del equipo,
acciones sobre equipos (encender, energía, mensajes, órdenes), tema claro, oscuro o como Windows, y actualizaciones
automáticas.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Si no, descarga `MeshCentralClient.exe` y
ábrelo; tenlo en una carpeta tuya para que pueda actualizarse. `MeshCentralClient.exe.sha256` es su huella.

## English

**MeshCentral Windows Client 0.11.0**

### New
- **Server** menu, next to "My account":
  - **Events**: the server's event log as the account sees it, newest first, with new events arriving live, a filter,
    and CSV export. In "Users", **Events…** shows what one account did.
  - **Reports**: the website's reports between two dates — remote sessions (by user, device or day, optionally with
    traffic), traffic per user, sign-ins (by user or day) and, for full administrators, database records — with CSV
    export. Only the choices the server accepts for each report are offered.
  - **Server state**, for administrators with server backup, restore or update rights: memory, load, connected agents
    and people, relayed sessions and agent errors, live; and the server's error log.
- **Notifications**: in "Users", **Send notification…** to everyone connected or to the chosen account; notifications
  that reach this app show in a small window at the bottom right that does not take the keyboard.

### Fixed
- Cancelling a download, or any request, at the wrong moment could close the connection with the device or the server.

### Good to know
- The server logs sign-ins on its website and with single sign-on, not this app's; the sign-in report says so.

### Also in this app
Sign-in with two-factor codes or single sign-on, live device list, remote desktop with several displays, terminal with
copy and paste as in PuTTY, files with the Windows clipboard, device details, device actions, device groups, users and
my account, light / dark / Windows theme, and automatic updates.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. Otherwise download `MeshCentralClient.exe` and run
it; keep it in a folder of yours so it can update itself. `MeshCentralClient.exe.sha256` is its fingerprint.

## Español

**MeshCentral Windows Client 0.11.0**

### Novedades
- Menú **Servidor**, junto a «Mi cuenta»:
  - **Sucesos**: el registro de sucesos del servidor tal como lo ve la cuenta, los más nuevos primero, con los nuevos
    llegando en vivo, filtro y exportación a CSV. En «Usuarios», **Sucesos…** enseña lo que hizo una cuenta.
  - **Informes**: los informes de la web entre dos fechas — sesiones remotas (por usuario, equipo o día, y si quieres
    con el tráfico), tráfico por usuario, entradas (por usuario o día) y, para administradores completos, registros de
    la base de datos — con exportación a CSV. Solo se ofrece lo que el servidor acepta en cada informe.
  - **Estado del servidor**, para administradores con permiso de copia, restauración o actualización del servidor:
    memoria, carga, agentes y personas conectadas, sesiones retransmitidas y errores de agentes, en vivo; y el registro
    de errores del servidor.
- **Avisos**: en «Usuarios», **Mandar aviso…** a todas las personas conectadas o a la cuenta elegida; los avisos que
  llegan a esta app salen en una ventana pequeña abajo a la derecha que no quita el teclado.

### Arreglado
- Cancelar una descarga, o cualquier petición, en mal momento podía cerrar la conexión con el equipo o con el servidor.

### Conviene saber
- El servidor apunta las entradas en su web y con inicio único, no las de esta app; el informe de entradas lo dice.

### Además, en esta app
Entrada con código de doble factor o inicio de sesión único, lista de equipos en vivo, escritorio remoto con varias
pantallas, terminal con copiar y pegar como en PuTTY, ficheros con el portapapeles de Windows, ficha del equipo,
acciones sobre equipos, grupos de equipos, usuarios y mi cuenta, tema claro, oscuro o como Windows, y actualizaciones
automáticas.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Si no, descarga `MeshCentralClient.exe` y
ábrelo; tenlo en una carpeta tuya para que pueda actualizarse. `MeshCentralClient.exe.sha256` es su huella.

## English

**MeshCentral Windows Client 0.18.0**

### New
- **Codes by email:** in My account, turn on or off a code sent to your email at each sign-in, when the server offers it.
- **Phone for SMS codes:** add a phone (the server checks it with a code by SMS) or remove it, when the server sends SMS.
- **Signing in** can ask for the code by SMS, as it already could by email.
- **New users** can be created with their email already checked, as the website does: with a mail server, MeshCentral
  asks for a checked email before the person can sign in.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. To install it, download `MeshCentralClient-Setup.exe`
and run it; or keep using `MeshCentralClient.exe` alone, as before. Each file has its `.sha256` fingerprint.

## Español

**MeshCentral Windows Client 0.18.0**

### Nuevo
- **Códigos por correo:** en Mi cuenta, activa o quita un código que llega a tu correo al entrar, si el servidor lo ofrece.
- **Teléfono para códigos por SMS:** pon un teléfono (el servidor lo comprueba con un código por SMS) o quítalo, si el
  servidor manda SMS.
- **Al entrar** se puede pedir el código por SMS, como ya se podía por correo.
- **Los usuarios nuevos** se pueden crear con el correo ya comprobado, como en la web: con servidor de correo, MeshCentral
  pide el correo comprobado antes de dejar entrar.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Para instalarla, descarga
`MeshCentralClient-Setup.exe` y ábrelo; o sigue usando `MeshCentralClient.exe` solo, como hasta ahora. Cada fichero
lleva su huella `.sha256`.

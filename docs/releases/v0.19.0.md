## English

**MeshCentral Windows Client 0.19.0**

### New
- **Codes to your phone (ntfy):** if you turned on, in the Android app, the codes that come to it with ntfy, signing in
  here can ask for the code to be sent to that phone.
- **My account** shows whether those codes are on, and can remove them (for example, if the phone is lost).

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. To install it, download `MeshCentralClient-Setup.exe`
and run it; or keep using `MeshCentralClient.exe` alone, as before. Each file has its `.sha256` fingerprint.

## Español

**MeshCentral Windows Client 0.19.0**

### Nuevo
- **Códigos a tu móvil (ntfy):** si activaste en la app de Android los códigos que le llegan con ntfy, al entrar aquí se
  puede pedir que el código vaya a ese móvil.
- **Mi cuenta** enseña si esos códigos están activados y permite quitarlos (por ejemplo, si se pierde el móvil).

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Para instalarla, descarga
`MeshCentralClient-Setup.exe` y ábrelo; o sigue usando `MeshCentralClient.exe` solo, como hasta ahora. Cada fichero
lleva su huella `.sha256`.

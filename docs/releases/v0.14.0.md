## English

**MeshCentral Windows Client 0.14.0**

### New
- **An installer:** `MeshCentralClient-Setup.exe` installs the app for your Windows account only, without administrator
  rights, under `%LOCALAPPDATA%\Programs`. It adds it to the Start menu (and, if you choose, the desktop) and to
  "Installed apps", from where it uninstalls cleanly. Your servers and settings stay.
- **It still updates itself:** installed or not, the app offers new versions as before, and "Installed apps" shows the
  version that actually runs.
- **Code signing policy:** what is signed, by whom, and what the app connects to, in `docs/CODE_SIGNING.md`. Free code
  signing by SignPath Foundation has been requested; this version is not signed yet.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. To install it, download `MeshCentralClient-Setup.exe`
and run it; or keep using `MeshCentralClient.exe` alone, as before. Each file has its `.sha256` fingerprint.

## Español

**MeshCentral Windows Client 0.14.0**

### Novedades
- **Un instalador:** `MeshCentralClient-Setup.exe` instala la app solo para tu cuenta de Windows, sin permisos de
  administrador, en `%LOCALAPPDATA%\Programs`. La pone en el menú Inicio (y, si quieres, en el escritorio) y en
  «Aplicaciones instaladas», desde donde se desinstala sin dejar restos. Tus servidores y ajustes se quedan.
- **Se sigue actualizando sola:** instalada o no, la app ofrece las versiones nuevas como hasta ahora, y «Aplicaciones
  instaladas» enseña la versión que de verdad corre.
- **Política de firma de código:** qué se firma, quién lo firma y a qué se conecta la app, en `docs/CODE_SIGNING.md`.
  Se ha pedido la firma gratuita de SignPath Foundation; esta versión aún no va firmada.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Para instalarla, descarga
`MeshCentralClient-Setup.exe` y ábrelo; o sigue usando `MeshCentralClient.exe` solo, como hasta ahora. Cada fichero
lleva su huella `.sha256`.

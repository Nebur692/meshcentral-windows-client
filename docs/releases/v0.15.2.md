## English

**MeshCentral Windows Client 0.15.2**

### Fixed
- **The signed-in user's terminal on Linux and macOS devices** asked the agent for the wrong kind of session (the one
  plugins use). It now opens the shell of whoever is signed in on the device, as the website does.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. To install it, download `MeshCentralClient-Setup.exe`
and run it; or keep using `MeshCentralClient.exe` alone, as before. Each file has its `.sha256` fingerprint.

## Español

**MeshCentral Windows Client 0.15.2**

### Arreglado
- **La terminal del usuario con sesión en equipos Linux y macOS** pedía al agente un tipo de sesión equivocado (el de
  los complementos). Ahora abre la shell de quien tiene la sesión abierta en el equipo, como hace la web.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Para instalarla, descarga
`MeshCentralClient-Setup.exe` y ábrelo; o sigue usando `MeshCentralClient.exe` solo, como hasta ahora. Cada fichero
lleva su huella `.sha256`.

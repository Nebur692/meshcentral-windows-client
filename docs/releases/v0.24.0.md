## English

**MeshCentral Windows Client 0.24.0**

### New
- **Agent console:** from the device's menu, commands to the device's MeshCentral agent itself (help, info, netinfo…),
  useful to look into an agent that misbehaves. Up and down bring back earlier commands.
- **Icon, ports and place:** the device's icon, its own ports when it does not use the usual ones (remote desktop, SSH,
  VNC and web) and its place on the server's map, when the server keeps places. Remote desktop, SSH and port mapping
  use those ports.

### Fixed
- **File times on Linux and macOS devices** were one hour (two in summer) late or early: their agent sends the time
  its own clock reads as if it were UTC. Now they show what the device's clock read, as `ls -l` there would. Windows
  devices were right and stay so.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. To install it, download `MeshCentralClient-Setup.exe`
and run it; or keep using `MeshCentralClient.exe` alone, as before. Each file has its `.sha256` fingerprint.

## Español

**MeshCentral Windows Client 0.24.0**

### Nuevo
- **Consola del agente:** desde el menú del equipo, órdenes al propio agente de MeshCentral del equipo (help, info,
  netinfo…), útil para mirar un agente que se porta raro. Arriba y abajo recuperan las órdenes anteriores.
- **Icono, puertos y ubicación:** el icono del equipo, sus puertos propios si no usa los normales (escritorio remoto,
  SSH, VNC y web) y su sitio en el mapa del servidor, si el servidor guarda ubicaciones. El escritorio remoto, SSH y la
  redirección de puertos usan esos puertos.

### Corregido
- **La hora de los ficheros de equipos Linux y macOS** salía con una hora (dos en verano) de diferencia: su agente manda
  la hora de su propio reloj como si fuera UTC. Ahora sale la que marcaba el reloj del equipo, como `ls -l` en él. Los
  equipos Windows ya salían bien y siguen igual.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Para instalarla, descarga
`MeshCentralClient-Setup.exe` y ábrelo; o sigue usando `MeshCentralClient.exe` solo, como hasta ahora. Cada fichero
lleva su huella `.sha256`.

## English

**MeshCentral Windows Client 0.25.0**

### New
- **Devices on the map:** in the server's menu, an OpenStreetMap map with a dot per device that has a place (set by
  hand, by GPS, by Wi-Fi or guessed from its address, in that order of preference, as the website), green when online.
  Its "Open" opens the device. It follows the live list. A device's place is set in "Icon, ports and place".

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. To install it, download `MeshCentralClient-Setup.exe`
and run it; or keep using `MeshCentralClient.exe` alone, as before. Each file has its `.sha256` fingerprint.

## Español

**MeshCentral Windows Client 0.25.0**

### Nuevo
- **Equipos en el mapa:** en el menú del servidor, un mapa de OpenStreetMap con un punto por equipo que tenga ubicación
  (puesta a mano, por GPS, por wifi o aproximada por su dirección, por ese orden de preferencia, como la web), verde si
  está en línea. Su «Abrir» abre el equipo. Sigue la lista en vivo. La ubicación de un equipo se pone en «Icono, puertos
  y ubicación».

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Para instalarla, descarga
`MeshCentralClient-Setup.exe` y ábrelo; o sigue usando `MeshCentralClient.exe` solo, como hasta ahora. Cada fichero
lleva su huella `.sha256`.

## English

**MeshCentral Windows Client 0.7.0**

### New
- **Device details** (right click → Device details, also for offline devices):
  - **General**: name, group, operating system, state, address, last connection and from where, last start, agent,
    CPU, BIOS and motherboard; **description and tags** can be edited.
  - **Network**: every interface with its MAC, addresses, gateway and speed.
  - **Inventory**: everything the agent sends about the hardware and itself, as a tree, with a filter.
  - **Notes**: edited and saved, and read back to make sure they were.
  - **History**: what happened on the device — sessions, file changes, edits — and who did it.

### Also in this app
Sign-in with two-factor codes or single sign-on, live device list, remote desktop with several displays, terminal,
files, light / dark / Windows theme, and automatic updates.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. Otherwise download `MeshCentralClient.exe` and run
it; keep it in a folder of yours so it can update itself. `MeshCentralClient.exe.sha256` is its fingerprint.

## Español

**MeshCentral Windows Client 0.7.0**

### Novedades
- **Ficha del equipo** (clic derecho → Ficha del equipo, también de equipos desconectados):
  - **General**: nombre, grupo, sistema operativo, estado, dirección, última conexión y desde dónde, último arranque,
    agente, CPU, BIOS y placa base; la **descripción y las etiquetas** se pueden editar.
  - **Red**: cada interfaz con su MAC, direcciones, puerta de enlace y velocidad.
  - **Inventario**: todo lo que manda el agente sobre el hardware y sobre sí mismo, en árbol y con filtro.
  - **Notas**: se editan y se guardan, y se releen para asegurarse de que quedaron guardadas.
  - **Historial**: lo que ha pasado en el equipo (sesiones, cambios de ficheros, ediciones) y quién lo hizo.

### Además, en esta app
Entrada con código de doble factor o inicio de sesión único, lista de equipos en vivo, escritorio remoto con varias
pantallas, terminal, ficheros, tema claro, oscuro o como Windows, y actualizaciones automáticas.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Si no, descarga `MeshCentralClient.exe` y
ábrelo; tenlo en una carpeta tuya para que pueda actualizarse. `MeshCentralClient.exe.sha256` es su huella.

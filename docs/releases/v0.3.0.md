## English

**MeshCentral Windows Client 0.3.0** — a modern Windows app for technicians, for any MeshCentral server.

### What it does
- Sign in with username and password, with two-factor codes; certificate fingerprint pinning for servers with their own certificate.
- Every device group and device the account can see, live, with search.
- **Terminal** on the device: cmd or PowerShell on Windows, shell elsewhere; copy and paste like Windows Terminal.
- **Light, dark or like Windows** theme.
- **New: it updates itself.** When a newer version is published here, the app offers it, downloads it, checks its SHA-256 fingerprint and restarts as the new version. A file that does not match is never installed.

### Install
Download `MeshCentralClient.exe` and run it: a single file, nothing to install. `MeshCentralClient.exe.sha256` is its fingerprint.

## Español

**MeshCentral Windows Client 0.3.0**: una app moderna de Windows para técnicos, para cualquier servidor MeshCentral.

### Qué hace
- Entrar con usuario y contraseña, con código de doble factor; huella fijada del certificado para los servidores con certificado propio.
- Todos los grupos y equipos que ve la cuenta, en vivo y con buscador.
- **Terminal** en el equipo: cmd o PowerShell en Windows y shell en el resto; copiar y pegar como en Windows Terminal.
- Tema **claro, oscuro o como Windows**.
- **Nuevo: se actualiza sola.** Cuando se publica aquí una versión más nueva, la app la ofrece, la descarga, comprueba su huella SHA-256 y se reabre ya actualizada. Un fichero que no coincide no se instala nunca.

### Instalar
Descarga `MeshCentralClient.exe` y ábrelo: es un único fichero, sin instalar nada. `MeshCentralClient.exe.sha256` es su huella.

## English

**MeshCentral Windows Client 0.20.0**

### New
- **Security keys and passkeys:** in My account, "Add a key…" with Windows' own window: Windows Hello (face,
  fingerprint or PIN), a USB or NFC key, or your phone by QR code. When signing in, "Use a security key".
- **Files:** typing a path completes it as you go, as Explorer does: the matching folders show below, the rest of the
  first one is written for you; Tab or → takes it, ↑↓ choose another, Enter opens, Esc closes.

### Fixed
- Removing a security key could say it was removed while the server kept it.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. To install it, download `MeshCentralClient-Setup.exe`
and run it; or keep using `MeshCentralClient.exe` alone, as before. Each file has its `.sha256` fingerprint.

## Español

**MeshCentral Windows Client 0.20.0**

### Nuevo
- **Llaves de seguridad y de acceso:** en Mi cuenta, «Añadir una llave…» con la ventana del propio Windows: Windows Hello
  (cara, huella o PIN), una llave USB o NFC, o tu móvil con un código QR. Al entrar, «Usar una llave de seguridad».
- **Ficheros:** al escribir una ruta se va completando, como en el Explorador: debajo salen las carpetas que encajan y se
  escribe el resto de la primera; Tab o → la toman, ↑↓ eligen otra, Intro abre y Esc cierra.

### Corregido
- Quitar una llave de seguridad podía decir que se había quitado aunque el servidor la conservara.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Para instalarla, descarga
`MeshCentralClient-Setup.exe` y ábrelo; o sigue usando `MeshCentralClient.exe` solo, como hasta ahora. Cada fichero
lleva su huella `.sha256`.

## English

**MeshCentral Windows Client 0.25.1**

### Fixed
- **When the connection to the server drops** (a network change, the PC waking up), the app now signs in again by itself,
  as the Android app does, waiting longer between tries; it only asks you when it cannot do it alone (single sign-on, or a
  second factor it cannot answer). A connection that stopped answering is noticed within a minute instead of looking open.
- Opening a tool on a dropped connection no longer fails with "The connection to the server was lost": the app says it is
  reconnecting.

### Install or update
If you have 0.3.0 or newer, the app offers this version by itself. To install it, download `MeshCentralClient-Setup.exe`
and run it; or keep using `MeshCentralClient.exe` alone, as before. Each file has its `.sha256` fingerprint.

## Español

**MeshCentral Windows Client 0.25.1**

### Corregido
- **Cuando se corta la conexión con el servidor** (un cambio de red, el PC al volver de suspensión), la app vuelve a
  entrar sola, como la de Android, esperando cada vez un poco más entre intentos; solo te pregunta si no puede hacerlo
  sola (inicio de sesión único, o un segundo factor que no puede contestar). Una conexión que dejó de contestar se nota en
  menos de un minuto, en vez de parecer abierta.
- Abrir una herramienta con la conexión caída ya no falla con «Se ha cortado la conexión con el servidor»: la app dice que
  está reconectando.

### Instalar o actualizar
Si tienes la 0.3.0 o una más nueva, la app te ofrece esta versión sola. Para instalarla, descarga
`MeshCentralClient-Setup.exe` y ábrelo; o sigue usando `MeshCentralClient.exe` solo, como hasta ahora. Cada fichero
lleva su huella `.sha256`.
